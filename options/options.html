Allow this extension in private windows

“Full photos and reviews” borrows a session from a private window, so the browser has to let this extension run there. Only you can switch that on

  1. You are on this extension’s Preferences tab. Click Details next to it.
  2. Find Run in Private Windows and choose Allow.
  3. Go back to Maps, open the toolbar panel and reload the tab.

In Chrome and Edge the switch is called Allow in Incognito (or Allow in InPrivate) on the extension’s details page.
